How to Organise and Preview an HTML Exercise

This guide helps students organise their HTML files and check their webpages before submitting their work.

1. Organise Your Files

Save each exercise in its correct folder. Keep related files together so that another student can find and update them.

  • Save the webpage with an appropriate .html filename.
  • Keep images in a clearly named images folder.
  • Use descriptive filenames that explain their purpose.

2. Preview Your Webpage

Save your work before opening the HTML file in a web browser. Check that the headings, paragraphs, links and images appear as expected.

  1. Save the file in VS Code.
  2. Open the HTML file in a browser.
  3. Check the page and correct any mistakes.

3. Check Before Submission

Before submitting, make sure the file is saved in the correct folder and that its content is complete.

  • Check spelling and heading order.
  • Check that links and image paths are correct.
  • Validate the HTML when internet access is available.

4. Maintenance Note

When updating this guide, keep the steps in a clear order and test any changes before sharing the page with classmates.
